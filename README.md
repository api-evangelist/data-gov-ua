# Official Ukrainian Government Portal (data-gov-ua)

Official Ukrainian Government Portal is a open data portal open-data portal for Ukraine running **CKAN**, exposing a standardized catalog API over ~38,895 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-gov-ua/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-gov-ua-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.7.2

## API
- **Official Ukrainian Government Portal CKAN Action API** — base `https://data.gov.ua/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.gov.ua)
- Live endpoint verified: `https://data.gov.ua/api/3/action/status_show` · ~38,895 datasets
